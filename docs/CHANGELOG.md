# eWorkHelper 变更记录

本文件是 eWorkHelper **唯一权威的发布历史**。根目录的 [`../RELEASE_NOTES.md`](../RELEASE_NOTES.md)
仅是对外发布摘要的索引，不再单独维护版本条目。

版本规则见 [`RELEASE.md`](RELEASE.md)，人工回归清单见 [`TESTING.md`](TESTING.md)。

---

## v1.2.0 — 2026-08-22

- 完成发布前整理与版本统一。
- 批量过滤支持多种文本匹配方式、AutoFilter 区域识别和本次过滤清除。
- 新增取消合并并填充，支持多选合并区域、公式 R1C1 复制和值填充。
- 新增 Ribbon 关于入口，动态显示程序集产品版本。
- 整理文档结构，移除阶段性过程记录，保留架构、功能、开发和发布规则。

## v1.1.260822.6 — 日期 2026-08-22（按版本号 `260822` 段推断）

- 建立四段式发布版本号规则（`Major.Minor.Patch.Revision`），修订号使用日期编码 `260822`。
- 批量过滤改用 Excel 原生 AutoFilter 值列表，不再创建辅助列或临时工作表。
- “清除本次过滤”限定为仅清除本工具最近处理的目标字段，保留其他字段筛选状态。
- 增加工作表校验与用户取消路径的处理，取消标题行选择时不修改工作表。
- 补充发布前安全检查、构建验证和人工回归要求。
- 同步整理 README 与 docs 的文档入口。
