# eWorkHelper 变更记录

本文件是 eWorkHelper **唯一权威的发布历史**。根目录的 [`../RELEASE_NOTES.md`](../RELEASE_NOTES.md)
仅是对外发布摘要的索引，不再单独维护版本条目。

版本规则见 [`RELEASE.md`](RELEASE.md)，人工回归清单见 [`TESTING.md`](TESTING.md)。

## v1.3.0 — 2026-09-20

- 集成 Excel 差异对比功能，支持多 Sheet 映射、差异高亮、基准值批注、行状态和可取消进度监控。
- 完善差异对比窗口布局、状态展示和安全取消/清理流程。
- 核心自动化测试扩展并完成现有功能回归验证。

## v1.2.0 — 2026-08-22

- 完成发布前整理与版本统一。
- 批量过滤支持多种文本匹配方式、AutoFilter 区域识别和本次过滤清除。
- 新增取消合并并填充，支持多选合并区域、公式 R1C1 复制和值填充。
- 新增 Ribbon 关于入口，动态显示程序集产品版本。
- 整理文档结构，移除阶段性过程记录，保留架构、功能、开发和发布规则。

## 研究文档 — 2026-09-19

## M1 技术原型 — 2026-09-19

- 新增独立于 Excel COM 的托管比较模型和按坐标逐格比较引擎。
- 新增 Excel Interop 批量读取与最小差异值写回原型。
- 新增核心自动化测试项目，13 项测试全部通过，并完成托管性能 smoke 验证。

- M1 不包含 Ribbon、正式 WinForms、完整格式/高亮/备注、多 Sheet GUI 或 P2 增强。

## M2 Excel 差异对比服务 — 2026-09-19

- 新增 `ExcelDiffService`，以候选工作簿副本为基础生成结果，支持临时文件、保存后验证、冲突拒绝、取消清理和源文件保护。
- 完善 `Value2`、公式、日期格式和 Excel 错误 HRESULT 的托管转换；保留公式、原始值、格式和错误元数据。
- 实现多 Sheet 一对一映射、差异高亮、自定义颜色、基准值传统备注及已有备注追加。
- 提供阶段进度、取消令牌、诊断日志和结构化执行结果，供后续 Ribbon/WinForms 调用；M2 不包含正式 GUI。
- 新增真实 Excel COM 合成工作簿集成测试；M1 核心测试 13/13 通过，M2 集成测试通过，验证源文件 hash、7 个差异、2 个 Sheet、备注、合并、冲突和取消路径。
- Go 原版在当前环境仍不可运行，未宣称原版运行对标通过；复杂格式对象和 Office 版本矩阵保留到 M4。

## M3 Excel 差异对比 GUI 集成 — 2026-09-19

## Excel 差异对比操作优化 — 2026-09-19

- Ribbon 点击时固定当前活动工作簿作为基准，界面只读显示完整路径，用户只需选择待比较工作簿；比较引擎和基准/候选方向不变。
- 启动及执行前拒绝未保存或已修改的基准；候选已打开且有未保存修改、与基准同文件时同样拒绝；关闭/重新打开或窗口期间保存修改基准均阻止继续执行。
- 已打开工作簿的 Sheet 枚举只临时借用 COM 引用，不会将用户工作簿当作临时文件关闭；切换候选清除失效映射。
- 新增基准身份、界面请求方向、双 Sheet 映射、候选切换及安全拒绝路径的合成 Excel 集成断言；真实 GUI 新流程和点击取消仍待人工验收。

## Excel 差异对比 GUI 优化 — 2026-09-20

- 补记用户对改版前 M3 流程的两项真实 Excel 人工验收通过（自动基准/双 Sheet 方向、中途取消和清理）；与本次自动化测试及改版后的待验项目分别记录。
- 重排 WinForms 窗口：基准文件名、完整路径和固定说明分层展示；Sheet 映射表改为弹性白底区域，空状态引导和长名称提示随增删更新。
- 修复状态内容截断及备注选项换行；阶段、差异数量和可滚动详情分开展示，并将原先未显示的进度条加入布局。
- 颜色预览与更改按钮分离；适度强调开始操作，区分取消比较与关闭，完成后提供可再次点击的“打开结果”。重试、取消、失败与无差异状态不沿用旧结果路径。
- 扩展真实 Excel COM 集成测试中的 WinForms 布局、模拟缩放、按钮状态及结果打开断言；实际 Windows 125%/150% DPI 与改版后 Ribbon 人工操作仍需目标桌面验收。

## Excel 差异对比增强 — 2026-09-20

- 差异对比窗口不再显示当前基准工作簿完整路径，仅显示固定的当前工作簿文件名；待比较工作簿选择保持不变。
- 将备注选项改为“基准内容写入批注”并在新窗口中默认勾选，仍允许用户关闭。
- 补齐现有进度接口适配类，并校正行状态与取消文案的过期集成测试预期；本轮核心测试、Excel 集成测试、Release 构建及两份开发清单签名验证通过。

- 增加独立托管进度监控：使用单调 `Stopwatch` 和每秒 `Timer` 快照，显示阶段、具体操作、当前 Sheet、工作量、差异/行状态统计、累计耗时、阶段耗时和最近进度时间；监控线程不访问 Excel COM，旧任务和关闭窗口回调不会覆盖或触碰已释放控件。
- 比较结果按相同行号聚合 `ADD`、`DEL`、`CHG` 行状态，保持既有按坐标逐格比较语义；结果副本的参与比较 Sheet 使用原生插列新增 A 列，原始差异高亮和基准值备注统一右移一列。
- 对含 `ListObject` 的参与比较 Sheet 拒绝不安全插列；结果仍以候选副本为基础，DEL 行不恢复基准内容。
- 核心自动化测试扩展到 16 项，覆盖行状态聚合和工作线程不回调时的独立计时。当前环境缺少 Visual Studio VSTO targets、Excel Interop 和 Excel 宿主，因此本条不宣称 VSTO、Excel COM 或 GUI 本轮实机验收通过。

## Excel 差异对比取消机制修复 — 2026-09-20

- 定位取消不及时根因：取消令牌原先只在 Sheet 边界、标记前和保存前检查，托管比较、批量读取后的循环、行状态写入、高亮和备注循环没有检查点；单次 Excel COM 调用本身也不能被令牌强行中断。
- 增加取消生命周期诊断轨迹：`CancelRequested`、`CancelObserved`、`BusinessStopped`、`CleanupStarted`、`CleanupCompleted`、`WorkerExited`，记录任务 ID、阶段、线程和相对耗时，不记录业务内容或路径。
- 增加托管比较、批量读取、状态列/高亮/备注处理和保存前后的安全检查；取消后跳过后续业务、不发布不完整结果，并对独立资源逐项清理。
- 取消请求后普通进度不再覆盖 GUI 状态，界面明确显示停止、清理和最终取消状态；新增托管取消响应和取消状态隔离测试。
- 当前环境仍缺少 Excel Interop、VSTO targets 和 Excel 宿主，COM 集成、GUI 人工取消、VSTO Release 与 Manifest 验证未执行。
